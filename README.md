# Sign Up Form – Java Swing

A simple **Sign Up Form** built in **Java Swing**.  
This project demonstrates GUI design, event handling, and file persistence in Java.  
User details (username, phone number, CNIC, and password) are saved into a text file (`users.txt`).

---

## Features
- Input fields for:
  - Username
  - Phone number
  - CNIC
  - Password
- Buttons:
  - **OK** – Saves user data to `users.txt`
  - **Cancel** – Exits the application
- Data persistence using `FileWriter`
- Error handling for file operations
- Confirmation dialog on successful registration

---

## Technologies Used
- Java (JDK 8+)  
- Java Swing – GUI framework  
- Java AWT – Event handling  
- File I/O – Persistent storage with `FileWriter`
